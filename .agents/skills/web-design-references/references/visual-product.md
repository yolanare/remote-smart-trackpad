# Visual direction and product patterns

Use galleries to discover examples, then inspect the selected artifact. An attractive screenshot establishes neither responsive behavior nor task success. Distinguish visual inspiration from an observed product flow.

## Recent

**Keywords:** art direction, typography, editorial, branding, website, app screenshot, visual identity.

**Observed:** [Recent](https://recent.design/) groups visual references across web, interface, branding, typography, motion, illustration, and editorial work. Separate browsing surfaces include websites, app screenshots, icons, and social preview images.

**Apply:** Use when a brief leaves visual direction open. Select the relevant medium, then compare a small number of examples for typography hierarchy, whitespace, color roles, image treatment, and density. Translate one coherent direction into reusable project tokens and layout rules.

**Limits / access:** The public index was readable, but the gallery is image-led and its individual visuals were not inspected in this review. Follow the selected reference to its original artifact where possible. Branding or print inspiration needs adaptation to web content, interaction, and responsiveness; the gallery supplies no implementation contract.

## CollectUI

**Keywords:** curated inspiration, website discovery, interface composition, visual alternatives.

**Observed:** [CollectUI](https://collectui.com/) currently presents curated website/interface inspiration, a subscription surface, and a latest-designs area. The retrieved page did not expose the familiar historical category-based archive or detailed design entries.

**Apply:** Use as secondary discovery when an accessible example matches the requested surface. Extract a specific compositional idea, then inspect the original website for behavior and responsive layout. Prefer a more directly searchable reference when the task already names a precise pattern.

**Limits / access:** The latest-designs content was not available in text extraction. Verify the live gallery before relying on category search or historical URLs. If it still exposes only the shell, use Recent for visual direction or Mobbin for a product pattern instead of inferring unseen examples.

## Mobbin

**Keywords:** real product, onboarding, checkout, paywall, settings, user flow, screen reference, MCP.

**Observed:** [Mobbin MCP](https://mobbin.com/mcp) advertises access to real product screens through an agent connection. Its public examples show comparative pattern analysis, including how upgrade screens present benefits, pricing, and calls to action. The page identifies paid-plan access for MCP.

**Apply:** Use for a concrete product question: what precedes an upgrade, which information belongs at a checkout step, or how settings are grouped. Search by task and platform. Where available, inspect adjacent screens so the adopted pattern fits a journey. Real-product examples provide evidence of use, not proof that they will work for this audience.

**Limits / access:** The public MCP description was reviewed; private search results and gated flows were not. Verify that relevant tools and account access exist before planning a tool workflow. Adapt mobile examples to web navigation and input. Borrow structure and interaction principles; use project-owned content and assets.

## 60fps

**Keywords:** interaction inspiration, gesture, onboarding feedback, sheet behavior, mobile reference.

**Contribution here:** [60fps](https://60fps.design/shots/filter) adds recorded interactions to visual discovery. It helps compare how products preserve context, reveal controls, or acknowledge an action over time, where a still screen leaves those decisions invisible.

**Apply:** Find examples of the same user task and identify which relationship makes the interaction understandable. Translate the pattern to web input and navigation before choosing an animation library. Read the [platform and access limits](motion.md#60fps) if using its recordings or MCP.
