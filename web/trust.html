Remote Smart Trackpad

Trust this PC

Once per phone. The remote then opens without warnings and installs as an app.

This phone already trusts this PC.

  1. Download the certificate

    Download

  2. Install it

    Settings → search “CA certificate” → Install anyway → choose the downloaded file.

    Allow the profile, then Settings → Profile Downloaded → Install.

    Settings → General → About → Certificate Trust Settings → turn on “Remote Smart Trackpad local CA”.

    Firefox also needs: Settings → About Firefox → tap the logo 5 times, then Settings → Secret settings → Use third party CA certificates.

    Other device

    Android: Settings → search “CA certificate” → Install anyway → choose the file.

    iPhone: install the downloaded profile, then enable it in General → About → Certificate Trust Settings.

  3. Open the remote

    Pair again, then choose Install app in the options or browser menu.
